.. index:: uncompute

uncompute command
=================

**Syntax:**


.. parsed-literal::

   uncompute compute-ID

* compute-ID = ID of a previously defined compute

**Examples:**


.. parsed-literal::

   uncompute 2
   uncompute lower-boundary

**Description:**

Delete a compute that was previously defined with a :doc:`compute <compute>`
command.

**Restrictions:** none

**Related commands:**

:doc:`compute <compute>`

**Default:** none
