.. index:: timestep

timestep command
================

**Syntax:**


.. parsed-literal::

   timestep dt

* dt = timestep size (time units)

**Examples:**


.. parsed-literal::

   timestep 2.0 
   timestep 0.003

**Description:**

Set the timestep size for subsequent simulations.

**Restrictions:** none

**Related commands:**

:doc:`run <run>`

**Default:**


.. parsed-literal::

   timestep 1.0
